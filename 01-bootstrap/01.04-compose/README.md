GitHub shows this file for the folder. A composition is a program that orders passes. It is not the semantics. The OKF index is [index.md](index.md).

- [01.04.01-pass](01.04.01-pass.md) is the `>>` object.
- [01.04.02-run](01.04.02-run.md) is the chain the walker actually runs.
- [01.04.04-build](01.04.04-build.md) and [01.04.03-inspect](01.04.03-inspect.md) are the longer chains, as signatures.
