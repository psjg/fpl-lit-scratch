* The grammar

Why: the surface syntax of FPL as decided in the combined draft (Grammar and
FON tabs, decisions S1–S41). What: a Lark LALR grammar with an indenter. Tabs
are indentation (one per level) and cell boundaries; seven enclosure pairs
=[ ] ( ) ⟨ ⟩ { }= plus the pre-lexed strings =“ ” 「 」= and block comments
=⟦ ⟧=; =;= comment levels; a token is any run of non-whitespace,
non-self-delimiting characters. Strings and comments never reach Lark: the
pre-lexer in the harness counts them by their own pair and stashes the
interior. Rung for the grammar against the harness: 2 (same definitions,
tested; the harness imports this file).

#+begin_src text :tangle gram/fpl.lark
// FPL surface grammar — prototype, 2026-09-27.
// Layers: (1) lexing splits on whitespace; enclosure delimiters and the bar self-delimit.
//         (2) enclosures are Dyck pairs (nesting rules below); indentation is the invisible pair.
//         (3) token shape (affixes, numbers, modifiers) is a regular post-pass, not in this grammar.
// Outside this grammar on purpose: named closers (heredocs, `end name`) are Type-1 and handled by a
// pre-lexer; saturation, arity and effects are typing, not parsing.

start: _NL* line*

// A line is a flat program; an optional indented block follows it (children first, post-order).
line: frames _NL block?
block: _INDENT line+ _DEDENT

// The bar separates frames; a tab separates cells within a frame (rank literals: space = token, tab = cell,
// newline = row); a frame is a sequence of cells, and in code a tab is simply a cell boundary too.
frames: frame (_BAR frame)*
frame: _TABS? (cell (_TABS cell)* _TABS?)?  // a run of tabs is one separator: no empty cells (an empty cell is written ⟨⟩)
cell: item+

?item: TOKEN
     | group
     | quotation
     | prefix
     | dict

// Enclosures — every one a distinct pair; interiors counted, so they nest in themselves.
// Strings “ ” and 「 」 and block comments ⟦ ⟧ are counted by the pre-lexer (see test harness):
// their interior is handed to the pair's interpreter, and islands ⟨ ⟩ inside “ ” are read recursively.
quotation: "[" _NL* frames? "]"                  // thunk / Code, decided by consumer; a quotation holds frames, so the bar is allowed inside
prefix:    "(" _NL* frames? ")"                  // reader op: rotate head to end, bar the arguments
group:     _LANGLE _NL* frames? _RANGLE
dict:      _LBRACE _NL* frames? _RBRACE       // S15: keys literal, values evaluated; entries by juxtaposition or by line               // evaluated enclosure: ⟨⟩ the empty list, ⟨1 2 3⟩ a list, ⟨expr⟩ an island in text


// A token is any run of non-whitespace, non-self-delimiting characters (Forth rule).
TOKEN.1: /[^\s\[\]()“”「」⟦⟧⟨⟩{}|⍝;]+/          // ; is self-delimiting: x; note
_BAR: "|"
_TABS: /\t+/
_LANGLE: "⟨"
_LBRACE: "{"
_RBRACE: "}"
_RANGLE: "⟩"

// Comments end at the newline, which is already structural. ; levels are the canon (S33): ; trailing, ;; before
// the next node, ;;; section, ;;;; file — the level is the attachment (see comments() in the harness). ⍝ is the glyph view.
LCOMMENT.2: /(;+|⍝)[^\n]*/
%ignore LCOMMENT

_NL: /(\r?\n\t*)+/                    // indentation is tabs only: one tab per level, a counter, no width comparison
%declare _INDENT _DEDENT
%ignore /[ \f]+/                      // spaces (and a form feed, the page separator) only; tabs are cell boundaries
#+end_src


* The harness: pre-lexer, indenter, affix pass, comment attachment

Why: everything the grammar cannot say. The pre-lexer counts the string and
comment pairs (no escapes anywhere), strips incidental indentation from
multiline strings (S26), refuses leading spaces (no Postel), and reports a
forgotten closer at the dedent that exposes it, naming the opener. The affix
pass reads a token's shape (prefixes =→ $ # & .. /=, suffix modifiers). The
comment pass attaches every =;= comment by level and position (S33). Running
the file parses the five glyph-spelling sources embedded in it and the six
name-spelling snippets under =gram/snips/=, and rejects three malformed
inputs. Language gotcha: this file is tab-indented Python, deliberately.

#+begin_src python :tangle gram/test_fpl.py
import re, sys
from lark import Lark
from lark.indenter import Indenter

class FplIndenter(Indenter):
	NL_type = '_NL'
	OPEN_PAREN_types = ['LSQB', 'LPAR', '_LANGLE', '_LBRACE']       # newlines inside [ ] and ( ) are not block structure
	CLOSE_PAREN_types = ['RSQB', 'RPAR', '_RANGLE', '_RBRACE']
	INDENT_type = '_INDENT'
	DEDENT_type = '_DEDENT'
	tab_len = 1

PAIRS = {'“': '”', '「': '」', '⟦': '⟧'}
KIND = {'“': 'str', '「': 'raw', '⟦': 'com'}

import re as _re
OPEN, CLOSE = '[(⟨{', '])⟩}'
def strict_indentation(code):
	"""No Postel: leading spaces outside brackets are an error. And the synchronisation rule that makes
	the newline a better ';': a bracket opened on a line at depth d may not stay open once a later line
	dedents below d. The error is reported THERE and names the opener, instead of 'unclosed at EOF'."""
	out, stack = [], []          # stack of (opener char, line no, indent)
	for n, l in enumerate(code.split('\n'), 1):
		indent = len(l) - len(l.lstrip('\t'))
		if not stack and l.lstrip('\t').startswith('\x00'):
			l = l.lstrip('\t').lstrip('\x00').lstrip(' ')
		elif not stack and _re.match(r'^\t* ', l):
			raise SyntaxError(f'line {n}: indentation must be tabs')
		if stack and l.strip() and indent < stack[-1][2]:
			c, m, _ = stack[-1]
			raise SyntaxError(f'line {n}: dedent below line {m}, but its {c} is still open')
		for ch in l:
			if ch in OPEN: stack.append((ch, n, indent))
			elif ch in CLOSE and stack: stack.pop()
		out.append(l.replace('\x00', ''))
	if stack:
		c, m, _ = stack[-1]; raise SyntaxError(f'line {m}: {c} never closed')
	return '\n'.join(out)

def prelex(src):
	"""The Dyck pre-lexer: count each string/comment pair, replace it by a placeholder token,
	keep its interior for the pair's interpreter. Overlap is impossible by construction:
	only the opener's own pair is counted."""
	out, stash, i = [], [], 0
	while i < len(src):
		c = src[i]
		if c in PAIRS:
			close, depth, j = PAIRS[c], 1, i + 1
			while j < len(src) and depth:
				depth += (src[j] == c) - (src[j] == close); j += 1
			if depth: raise SyntaxError(f'unclosed {c} at {i}')
			interior = src[i+1:j-1]
			if KIND[c] == 'str':
				# S26: incidental indentation. Strip from each continuation line as many leading tabs as the
				# block depth of the line the string opens on; the printer puts them back. Raw strings keep everything.
				line_start = src.rfind('\n', 0, i) + 1
				depth = len(src[line_start:i]) - len(src[line_start:i].lstrip('\t'))
				parts = interior.split('\n')
				interior = '\n'.join([parts[0]] + [p[depth:] if p.startswith('\t' * depth) else p for p in parts[1:]])
			if KIND[c] != 'com':
				stash.append((KIND[c], interior)); out.append(f'¶{KIND[c]}{len(stash)-1}')
			else:
				out.append('\x00')  # a removed comment leaves a marker so postel does not read the gap as indentation
			i = j
		else:
			out.append(c); i += 1
	return strict_indentation(''.join(out)), stash

def islands(interior):
	"""Inside an interpolating string: split into text chunks and ⟨ ⟩ islands (counted), and
	read each island with the grammar — the pair names the interpreter, recursively."""
	parts, i, buf = [], 0, ''
	while i < len(interior):
		if interior[i] == '⟨':
			depth, j = 1, i + 1
			while j < len(interior) and depth:
				depth += (interior[j] == '⟨') - (interior[j] == '⟩'); j += 1
			if depth: raise SyntaxError('unclosed island')
			if buf: parts.append(('text', buf)); buf = ''
			parts.append(('island', parser.parse(interior[i+1:j-1] + '\n')))
			i = j
		else:
			buf += interior[i]; i += 1
	if buf: parts.append(('text', buf))
	return parts

MODS = '´`¨˜⁼˙'
SHAPE = re.compile(rf'''
	^(?P<prefix>→|\$|\#|\&|\.\./|\.\.)?          # prefix sigils
	 (?P<body>[^{MODS}]*?)                  # the name or number (may contain / for paths)
	 (?P<mods>[{MODS}]*)$                   # suffix modifiers
''', re.X)
NUM = re.compile(r'^-?(\d+(\.\d+)?|∞|π)$')

def shape(tok: str):
	m = SHAPE.match(tok)
	assert m, tok
	p, body, mods = m.group('prefix') or '', m.group('body'), m.group('mods')
	kind = 'modifier' if not body else 'string' if body.startswith('¶') else 'number' if NUM.match(body) else ('path' if '/' in body else 'name')
	return dict(prefix=p, kind=kind, body=body.split('/') if kind == 'path' else body, mods=list(mods))

# ── comments as trivia by identity: the level is the attachment (S33) ─────────────────────
def comments(src):
	"""Classify every ; comment by level and position and say what it attaches to.
	;    after code on the line      → that line's node (trailing)
	;;   own line, block indentation → the next code line in the block (before); on a definition head: its doc
	;;;  own line, column 0          → section heading for the enclosing directory/file
	;;;; column 0                    → the file/module
	Comments are not parsed by Lark (they are %ignore'd); this pass reads them off the source so the
	printer can serialise them back by identity."""
	lines = src.split('\n'); out = []
	for n, l in enumerate(lines, 1):
		m = _re.search(r'(?<![^\s\t]);+', l) if ';' in l else None
		if not m: continue
		lvl = len(m.group(0)); text = l[m.end():].strip(); code = l[:m.start()].strip()
		if code:
			out.append((n, lvl, 'trailing', n, text)); continue
		indent = len(l) - len(l.lstrip('\t'))
		if indent == 0 and lvl >= 3:
			out.append((n, lvl, 'file' if lvl >= 4 else 'section', None, text)); continue
		nxt = next((k for k in range(n, len(lines)) if lines[k].strip() and not _re.match(r'^\s*;', lines[k])), None)
		prv = next((k for k in range(n - 2, -1, -1) if lines[k].strip() and not _re.match(r'^\s*;', lines[k])), None)
		HEAD = r'^\t*\S+\s*:\s'
		kind, target = 'before', (nxt + 1) if nxt is not None else None
		if nxt is not None and _re.match(HEAD, lines[nxt]): kind = 'doc'                      # ;; above a head (Lisp, Rust)
		elif prv is not None and _re.match(HEAD, lines[prv]) and indent > len(lines[prv]) - len(lines[prv].lstrip('\t')):
			kind, target = 'doc', prv + 1                                                     # ;; as the body's first line (Python)
		out.append((n, lvl, kind, target, text))
	return out

* The canonical printer and the two printer laws

Why: claim 10 of the syntax document — =print ∘ parse = canonicalize= on
source and =parse ∘ print = id= on canonical trees — held as Hypothesis
properties, 2000 examples each, from two generators: =from_lark= over the
flat fragment and a tree strategy with nested blocks. Rung 2.

#+begin_src python :tangle gram/printer.py
"""Canonical printer for the FPL surface grammar, and the two printer laws as property tests.

    parse ∘ print = id            on trees   (print then parse gives the same tree back)
    print ∘ parse = canonicalize  on source  (printing is idempotent: print(parse(print(parse(s)))) == print(parse(s)))

Two generators: (a) hypothesis.extra.lark.from_lark over the flat fragment of the grammar
(no off-side blocks, since declared INDENT/DEDENT terminals have no pattern to generate from);
(b) a hand-written tree strategy that does include nested blocks, printed with indentation.
"""
import re
from lark import Lark, Tree, Token
from hypothesis import given, settings, strategies as st, HealthCheck
from hypothesis.extra.lark import from_lark
from test_fpl import parser, prelex, FplIndenter, shape

GRAMMAR = open('fpl.lark', encoding='utf-8').read()

# ── the canonical printer ────────────────────────────────────────────────────────────────
def p_items(items):
    return ' '.join(p_item(i) for i in items)

def p_item(i):
    if isinstance(i, Token):
        return i.value
    inner = [c for c in i.children if isinstance(c, Tree)]
    body = p_frames(inner[0]) if inner else ''          # a group of only tabs prints like an empty group
    o, c = {'quotation': '[]', 'prefix': '()', 'group': '⟨⟩', 'dict': '{}'}[i.data]
    return o + ' ' + body + ' ' + c if body else o + c
    raise ValueError(i.data)

"""FON-data: the inert, braced data profile of FPL (decisions S15, S17, S21, S22, S24 of the FON tab).

Grammar: pure Dyck — no off-side rule, no islands, no dialect pairs, no comments. Whitespace is token
separation only, in any amount. Strings “ ” and 「 」 are counted by the same pre-lexer as the code grammar.
Reader: INERT. It never evaluates, resolves or constructs typed objects: names are symbols, [ ] is Code
(opaque), ( ) is a tagged tuple, { } a dict with literal keys (a repeated key is a parse error), numbers
are exact decimals, _ is absence, and name / $name / #hash are three kinds of reference VALUE the reader
does not follow. Bounds (depth, token length, input size) are parameters of the recogniser, not accidents.
"""
import re, json
from decimal import Decimal
from dataclasses import dataclass
from lark import Lark, Tree, Token, Transformer
PAIRS = {'“': '”', '「': '」', '⟦': '⟧'}
KIND  = {'“': 'str', '「': 'raw', '⟦': 'com'}

def prelex(src):
    """The counting pre-lexer (same as the code grammar's): each string/comment pair by its own opener
    and closer; the interior is stashed for the pair's interpreter. No indentation rule here: the braced
    profile has none."""
    out, stash, i = [], [], 0
    while i < len(src):
        c = src[i]
        if c in PAIRS:
            close, depth, j = PAIRS[c], 1, i + 1
            while j < len(src) and depth:
                depth += (src[j] == c) - (src[j] == close); j += 1
            if depth: raise SyntaxError(f'unclosed {c} at {i}')
            if KIND[c] != 'com':
                stash.append((KIND[c], src[i+1:j-1])); out.append(f'¶{KIND[c]}{len(stash)-1}')
            i = j
        else:
            out.append(c); i += 1
    return ''.join(out), stash

FON_GRAMMAR = r"""
start: value*
?value: TOKEN | list | dict | tuple | code
list:  "⟨" value* "⟩"
dict:  "{" (TOKEN value)* "}"          // keys are literal tokens (symbols), never evaluated
tuple: "(" value* ")"                  // a tagged tuple: the head is data, never called
code:  "[" value* "]"                  // Code, opaque to the data reader
TOKEN: /[^\s\[\]()“”「」⟦⟧⟨⟩{}|⍝]+/
%ignore /\s+/
"""
parser = Lark(FON_GRAMMAR, parser='lalr')

class Absent:                              # _ : unspecified here; in a data position, a masked element
    def __repr__(self): return '_'
    def __eq__(self, o): return isinstance(o, Absent)
    def __hash__(self): return 0

@dataclass(frozen=True)
class Sym:  name: str                      # a bare name: a petname reference, or a symbol; not resolved
@dataclass(frozen=True)
class Cell: name: str                      # $name: reference by identity; not followed
@dataclass(frozen=True)
class Hash: hex: str                       # #hash: reference by content; not followed
@dataclass(frozen=True)
class Str:  text: str; raw: bool = False   # “…” interpolating (kept as text here) or 「…」 raw
@dataclass(frozen=True)

@dataclass(frozen=True)

NUMBER = re.compile(r'^-?(0|[1-9][0-9]*)(\.[0-9]+)?$')     # exact decimal, canonical: no +, no leading zeros, no exponent
HEXFLT = re.compile(r'^-?0x(0|1)(\.[0-9a-f]*[1-9a-f])?p-?(0|[1-9][0-9]*)$')   # IEEE binary float, C99 %a: exact bits, no rounding anywhere

class Bounds(Exception): pass

class Reader(Transformer):
    def __init__(self, stash, max_depth):
        super().__init__(); self.stash = stash; self.max_depth = max_depth
    def TOKEN(self, t):
        s = t.value
        if s == '_': return ABSENT
        if s in ('true', 'false'): return s == 'true'
        if s in ('∞', '-∞', 'nan', '-nan'): return Flt(float(s.replace('∞', 'inf')))
        if HEXFLT.match(s): return Flt(float.fromhex(s))
        if s.startswith('¶'):
            kind, idx = s[1:4], int(s[4:]); return Str(self.stash[idx][1], raw=(kind == 'raw'))
        if NUMBER.match(s): return Decimal(s)
        if re.match(r'^-?(0x|[0-9])', s): raise SyntaxError(f'non-canonical number {s}')   # 01, 1e5, +1, 1., 0x1.80p+3: a parse error, never a symbol or a lenient read
        if s.startswith('$'): return Cell(s[1:])
        if s.startswith('&'):
            if not HASH.match(s): raise SyntaxError(f'malformed hash reference {s}')
            return Hash(s[1:])
        if s.startswith('#'): return Sym(s[1:])          # #name: the symbol itself (same value as a bare name in the data profile)
        return Sym(s)
    def list(self, xs):  return list(xs)
    def tuple(self, xs): return Tagged(tuple(xs))
    def code(self, xs):  return Code(tuple(xs))
    def dict(self, xs):
        d = {}
        for k, v in zip(xs[::2], xs[1::2]):
            if k in d: raise SyntaxError(f'repeated key {k}')      # never first-wins/last-wins: a parse error
            d[k] = v
        return d
    def start(self, xs): return xs[0] if len(xs) == 1 else list(xs)

def depth_of(t, d=0):
    return max([d] + [depth_of(c, d + 1) for c in t.children if isinstance(c, Tree)])

def read_fon(text, max_depth=64, max_token=4096, max_size=1 << 24):
    """Total, linear recogniser from bytes to value. Bounds are part of the profile."""
    if len(text) > max_size: raise Bounds('input too large')
    text.encode('utf-8')                                       # str is valid Unicode by construction; bytes come in validated
    code, stash = prelex(text)                                 # strings first, so their newlines survive
    tree = parser.parse(code)
    if depth_of(tree) > max_depth: raise Bounds('nesting too deep')
    for tok in tree.scan_values(lambda v: isinstance(v, Token)):
        if len(tok) > max_token: raise Bounds('token too long')
    return Reader(stash, max_depth).transform(tree)

def write_fon(v):
    if v is ABSENT: return '_'
    if isinstance(v, bool): return 'true' if v else 'false'
    if isinstance(v, Flt):
        import math
        x = v.bits
        if math.isnan(x): return '-nan' if math.copysign(1, x) < 0 else 'nan'
        if math.isinf(x): return '∞' if x > 0 else '-∞'
        h = x.hex()                                              # e.g. -0x1.8000000000000p+3
        m, e = h.split('p'); e = e.replace('+', '')
        m = m.rstrip('0').rstrip('.') if '.' in m else m
        return m + 'p' + e
    if isinstance(v, Decimal):
        s = format(v, 'f'); return s if NUMBER.match(s) else format(v.normalize(), 'f')
    if isinstance(v, Sym): return v.name
    if isinstance(v, Cell): return '$' + v.name
    if isinstance(v, Hash): return '&' + v.hex
    if isinstance(v, Str): return ('「' + v.text + '」') if v.raw else ('“' + v.text + '”')
    if isinstance(v, list): return '⟨ ' + ' '.join(map(write_fon, v)) + ' ⟩' if v else '⟨⟩'
    if isinstance(v, Tagged): return '( ' + ' '.join(map(write_fon, v.items)) + ' )' if v.items else '( )'
    if isinstance(v, Code): return '[ ' + ' '.join(map(write_fon, v.items)) + ' ]' if v.items else '[ ]'
    if isinstance(v, dict): return '{ ' + ' '.join(k.name + ' ' + write_fon(x) for k, x in v.items()) + ' }' if v else '{ }'

;;; ── 1. constructors run backwards: a pattern is the inverse of an injective constructor ──
circle : r -- shape
	#circle swap pair
rect : w h -- shape
	#rect swap pair pair

area : shape -- n
	match
		( circle r ∈ pos )	r dup times π times	; guard: an ascription in the pattern, no `when`
		( circle 0 )	0	; a literal matches by equality
		( rect w h )	w h times
		_	?	; wildcard row; its body is a goal the elaborator reports (S40)

;;; ── 2. the same, Haskell's way: the pattern in the head (S37, on the table) ──
perimeter : ( circle r ) -- n
	r τ times
perimeter : ( rect w h ) -- n
	w h + 2 times

;;; ── 3. multiple dispatch (Julia, CLOS): patterns on every argument, typed ──
collide : a b -- outcome
	match
		( _ ∈ Asteroid )	( _ ∈ Ship )	#boom
		( _ ∈ Ship )	( _ ∈ Asteroid )	swap collide	; symmetric case delegates
		( _ ∈ Ship )	( _ ∈ Ship )	#bounce
		_	_	#miss	; catch-all: without it the match is partial and carries +fail
	; static where the types are known (row 23); a dynamic site declares +fail (X20)

;;; ── 4. list patterns without a star: cons is injective, catenation is not (S38) ──
sum : xs -- n
	match
		⟨⟩	0
		( cons x xs )	xs sum x +
zip : xs ys -- ps
	match
		( cons x xs )	( cons y ys )	xs ys zip x y pair cons
		_	_	⟨⟩
contains : x xs -- b
	match
		_	⟨⟩	false
		_	( cons $x _ )	true	; $x: a pinned pattern, matches the current value of x (Elixir's ^x)
		_	( cons _ rest )	x rest contains
; a sequence queried as a whole is a value-level query, where a regex belongs:
;   lines [ “err.*” regex ] find

;;; ── 5. Prolog's family: the same match, inside a space, is two-way unification ──
family/
	parent : x y --	; a relation: two pattern cells, an empty body = succeed
		match
			#tom	#bob
			#bob	#ann
			#bob	#pat
			#pat	#jim
	male : x --
		match
			#tom
			#bob
			#jim
	female : x --
		match
			#ann
			#pat
	mother : x y --
		x y parent  x female
	grandfather : x z --

		x y parent  y z parent  x male

#pat #jim family/parent	; outside a space: one-way, first match, deterministic; succeeds
[ fresh →g  g #jim family/grandfather  g ] logic/space	; inside: fresh g unifies against the rows → [ #bob ]
