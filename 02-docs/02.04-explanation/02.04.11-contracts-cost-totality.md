# 02.04.11 2026-09-28 — Contracts, cost and totality

Three things the checker says about a definition: what it promises (contracts), what it costs
(a grade), and that it terminates (a ladder). They share one idea from the
[substrate](02.04.04-substrate.md): the verification ladder is over the *same definitions*, so a
property written once is proved, tested or checked depending on how much the operator has paid for.
The hole discipline that governs the cheap end is in
[principles](02.04.07-principles-and-privileges.md).

## 1 Contracts: rung 3 of one predicate

A contract is not a new mechanism: the syntax already has `⊨`, a definition has `mean/contract`,
and the gradual boundary turns an undischarged obligation into a blame-carrying check. A contract
predicate is an ordinary word `x -- bool`: `⊢` proves it (rung 1, erased), property testing samples
it (rung 2, same definition), `⊨` checks it at run time with blame (rung 3). Cost is bounded three
ways: never in proved code (grade 0, erased); checks only at holes and unverified boundaries, not
at every boundary; on/off is a dispensatie (`../adyton/unchecked`) with the hole recorded;
higher-order contracts (wrappers on thunks, checked at `!`) only at the unverified boundary.
The clock-extent check against the log was already a contract with blame on the late event.

**Against Eiffel, explicated** so humans and agents recognise it:

| Eiffel | Here |
| --- | --- |
| `require` | precondition on inputs (blame: caller) |
| `ensure` | postcondition on outputs (blame: supplier) |
| `old x` | a reference to the previous frontier in the log (`xs old` in an `ensure` body, a word not a sigil) |
| class invariant | invariant on an object directory (a coalgebra invariant), checked on every send that touches state, and at the moment of escalation |
| loop `variant` | subsumed by the totality checker (a word without `+div` terminates, proved) |
| `check` | `⊨` inline |
| `rescue`/`retry` | restarts and `/` ([failure](02.04.08-capabilities-effects-failure.md)); a `⍣` clause of the word |
| assertion levels (a global switch) | a dispensatie per hole, finer and recorded |
| subcontracting under inheritance | contracts on the structural interface (`has/norm/contract` binds every implementer), without classes and without the LSP trap |
| missing frame conditions | the absence of `out` capabilities: what a word may not do |
| runtime-only checking | three rungs on one predicate, the contract being the prover's spec |

Strictly better on six points (erase-on-proof, blame at holes only, `old` as log, variant as
totality, frames from capabilities, subcontracting without classes); worse on one, salience:
`require`/`ensure` sit in a fixed place in every Eiffel routine, ours in a directory. Hence fixed
child clauses: `require`, `ensure`, `rescue` ([objects](02.04.09-objects-dispatch-visibility.md)).

**Syntax verdict.** No new syntax: `require`, `ensure`, `rescue` are words that head child blocks
inside a definition's body exactly as `if`/`each` head theirs (inline `require [ xs shape first 0 >
]` or unfolded), and the elaborator records each as an entry of the word's directory (`mean/require`,
`mean/ensure`, `mean/rescue` beside `mean/doc`). Canonical child order is a printer rule: doc,
require, body, ensure, rescue. The interface view is the same list without the body and is what the
interface hash covers. Aliases `pre`/`post`/`precondition`/`postcondition` (and Hoare's
vocabulary) are accepted on input and canonicalised; whoever types `precondition` reads `require`
back. Clauses as paths: `f/1/require` is the clause's child and prints under the clause; the
word-level `f/require` is the outer contract over all clauses (Eiffel's subcontracting, per
clause). Entries are filed by prelude macros before saturation ([syntax rationale](02.04.05-syntax-rationale.md)).
Contracts are in the interface hash (a stronger precondition breaks callers, so that cascade is
correct); the short form is Eiffel's "short form" as the interface view
([history](02.04.10-history-store-distribution.md)).

**Rescue and invariants.** A routine succeeds or fails, and a failing routine restores its
invariant before propagating (Meyer's "organized panic"): the invariant of the object directory
must hold at escalation, a contract on `/`, beside the rule that linear resources are released or
offered first.

## 2 Cost is a grade

Resource Aware ML (Hoffmann et al.) derives upper bounds on worst-case and lower bounds on
best-case resource use automatically, and can determine constant resource use; multivariate
resource polynomials, inference by linear programming over potential annotations on types
(automatic amortised resource analysis, AARA); higher-order, polymorphic, with side effects,
parallelism, and in its recent version effect handlers. Three consequences.

1. Cost is a third grade semiring after linearity and information flow: `(ℕ, +, ×)` or tropical `(max, +)` (Dal Lago–Gaboardi's linear dependent types; Granule's `Nat` grades). AARA *is* grade inference: the potential annotations are grades, so the bound-computing algorithm is an inference mode of the type system, not a tool beside it.
2. The fuel of cooperative scheduling is exactly the step-count metric per segment between yield points; a proven bound on steps between yields is what a cooperative scheduler needs ([concurrency](02.04.14-concurrency-logic-search.md)). Constant-resource analysis is constant-time as a type, moving the side-channel item from "not covered" to "partly covered by grades".
3. What is and is not computable: polynomial bounds, automatically, above and below; not non-polynomial bounds, and not data-dependent control flow where RaML itself fails; there: user annotations (checkable), a `sorry`, or a hole. Exact bounds need dependent grades, manual (calf-style).

Honest status: nothing computes yet (no elaborator); what exists is the slot (the cost semiring in
B2), the algorithm (AARA as LP inference in B0), the theorem class (soundness w.r.t. a cost
semantics) and an oracle for differential testing: RaML on translations of the same definitions.
Cost at the machine level (`cost@M`, `ensure cycles ≤ N`) is in
[assurance](02.04.12-compiler-backends-assurance.md); a load from a non-resident segment carries a
cost effect ([history](02.04.10-history-store-distribution.md)).

## 3 Totality is a ladder

No one writes everything in Walther recursion. The checker is a ladder, in the order Agda, Lean,
Idris and Dafny converged on:

1. **structural**: recursion on a strict subterm, free;
2. **Walther recursion** (decidable class where arguments shrink through "reducers"), inferred, free;
3. **well-founded with a measure**: a `decreasing_by` measure with a proof that it falls, one line;
4. **sized / fuel**: productivity for codata and search spaces, the step grade, the bound;
5. **`+div`**: nothing proved, honestly marked, one word on the effect line.

You write what you want; the checker says which rung it landed on. Most of the time none is needed:
in the array and concatenative style explicit recursion is rare, since `¨`, reductions, scans and
`n ⍟` are *bounded* combinators, total by construction, and servers are codata. That is Bosque's
insight (regularised programming: loops replaced by functor operations, real recursion requiring an
explicit keyword) with the type system added: loops are combinators, recursion is allowed, and
`+div` is our `recursive`, weaker in what it demands and stronger in what it says.

**`recur` and refinements.** `recur` (structural, default), `recur/tail`, `recur/walther`,
`recur/measure` are claims the checker verifies (Clojure's `recur` the precedent for explicit
checked tail recursion); if no rung holds, `+div` bubbles to the effect line. An experienced reader
sees the residual: `recur/tail` is a loop, `recur/measure` a bounded stack. Syntactically `recur`
heads a child `measure [ … ]`, entry `f/recur/measure`. Reactivity: CSP is the nondeterministic
member of the family; single-assignment dataflow is Kahn (deterministic); FRP in Elliott's sense is a
coalgebra over the clock; of the three variants two log nothing
([concurrency](02.04.14-concurrency-logic-search.md)). Bounded search is `space` as codata (the
delay monad), priced by fuel rather than `+div`.
