## 1 The parallelism map

Three classes, and the class decides what is logged.

1. **Deterministic parallel** (log nothing; confluent): arrays, `¨`, scans, reductions in the pure fragment; fork-join with a work-stealing scheduler as a trusted handler (Cilk/Rayon); interaction nets for the dup-free fragment.
2. **Deterministic concurrency** (log nothing): Kahn process networks (blocking reads over FIFO channels are deterministic whatever the scheduling) and single-assignment dataflow variables (Oz's declarative concurrency). `fresh` as a runtime logic variable that suspends its consumers is the dataflow variable, its `unify` the tell. Servers and pipelines are written this way without touching `select`. Four precisions (from CTM and Kahn): (a) Kahn's condition is blocking reads only: no `select`, `alt`, poll or timeout; (b) confluence holds given no cells and no ports, and with exceptions the model is declarative only where none is raised, so a class-2 subtree is `+fail`-free or merges its failures deterministically (all of them, as a set); (c) membership is *derived by absence*: a subtree is class 2 iff it holds no cell, no port, no `select` capability and no `+fail` on its effect line, no declaration needed, and `under batch` is then automatic on it; (d) lazy declarative concurrency (demand-driven Kahn, by-need on the dataflow variable) belongs to the same class. Cell and port capabilities are the only things that move a subtree to class 3.
3. **Nondeterministic concurrency** (log the choices): CSP channels (synchronous rendezvous as a linear pair) and Erlang mailboxes (asynchronous, owned by a frame), both channels with typestate and `select`/`alt` a logged choice; actors with supervision. Green threads and fibers are a mechanism, not a class (a scheduler is a handler; preemption needs the timer capability); STM is a fork of the log committed if it commutes, `retry` a restart, `orElse` `∨`, "no I/O in a transaction" a type; futures are a thunk plus a channel with OCapN pipelining.

The honest reduction is *two* primitives on one log: pure parallel subtrees, and actors with
channels (an actor is an object directory plus a mailbox channel plus a supervisor `..` plus a
budget), everything else an instance or an implementation. Each concurrency handler states which CTM
theorem it keeps: confluence, determinism given no shared cells, or neither. The typed runtime
metavariable has shipped (Alice ML: typed futures and promises, with a proved uniform confluence
for the typed fragment, and linear types for promises to enforce single assignment): FPL's
`fresh` is Alice's promise with a uniqueness grade. Reactivity: CSP is the nondeterministic member;
single-assignment dataflow is Kahn; FRP is a coalgebra over the clock; only the variant with
`merge`/`select` is CSP ([totality](02.04.11-contracts-cost-totality.md)).

**Supervision.** A cycle in restart authority has no fixed point (both die: nobody restarts; both
live and disagree: oscillation); a tree has a root that lives or is the only panic. Erlang separates
*links* (symmetric fate-sharing) from *monitors/supervisors* (asymmetric restart): within an image
symmetric links are allowed and useful, restart authority stays a tree. Between images mutual
revival is a protocol, not a cycle: heartbeats on the time capability, checkpoint-plus-replay, and a
*tiebreak rule* (lowest `$` restarts first, or a third decides), as Minix 3's reincarnation server
and Hurd's servers needed. Who restarts is decided by a rule, never by a cycle.

**Multikernel.** Barrelfish's insight (a multicore is a distributed system) is C4 taken literally:
one image per core or NUMA node, a replicated log between them, shared memory only as the
*implementation* of a channel with fences as the backend's refinement, so the memory-model debt is
paid once per backend ([history](02.04.10-history-store-distribution.md)). Data parallelism within a
core (SIMD), single-threaded hot loops and job systems are untouched; lock-free queues, ring buffers
and double-buffered state are channel implementations; raw shared memory with atomics stays on the
machine tier under `+nefas`. Still open, all library or contract work: the scheduler contract, the
granularity the cost model must supply for "free" parallelism to be profitable, and deadlock-freedom
theorems per channel library.

## 2 Scheduling contexts are capabilities

The precedent is seL4 MCS: scheduling contexts are kernel objects passed as capabilities with a
budget and a period. Time is a capability, so every frame holds a scheduling context and without a
budget nothing runs. **Real-time by default**: every frame has budget and period, the root scheduler
is EDF or rate-monotonic, latency is bounded for the whole image (*soft* real-time everywhere,
*hard* only where the allocation-free fragment proves it; the name must carry the difference).
**Batch as a privilege** ([principles](02.04.07-principles-and-privileges.md)): `under batch` gives
a subtree an unbounded budget and work-stealing without preemption, and those are exactly the pure
subtrees (class 1 and Kahn networks); declarative concurrency and batch scheduling are the same
subtree. **Priority inversion** is solved by the creation chain: a frame inherits its parent's
budget (priority inheritance along `..`), and a loan of budget is a logged capability grant. Every
scheduler decision is an event, so replay reproduces scheduling; a missed deadline is an event with
provenance; real-time analysis is a query on the log.

## 3 Traces, profiles, cooperative scheduling, deadlock

**Observability.** A stack trace is the `..` chain at an event, present on every escalation; a
profile is the time capability read at frame boundaries, reproducible by replay; flame graphs are
views, the static call graph is the authority graph ([capabilities](02.04.08-capabilities-effects-failure.md)).
Frame entry and exit are *not* events by default; granularity is switched on per passage with a
privilege (`under trace`) or obtained by sampling on a timer capability. Free is the machinery, not
the granularity.

**Cooperative where proven.** Preemption exists to interrupt untrusted code that will not yield. If
the checker proves a frame does a bounded number of steps between two yield points (productivity
with fuel, the cost grade), a timer is unnecessary: the compiler inserts yields at loop back-edges
with a proven bound and the scheduler is cooperative (Erlang preempts by reduction count, a compiler
inserted yield; Go had to add asynchronous preemption because it had no bounds). Every section
between yields has a WCET, so EDF over cooperative sections is a schedulability analysis, not a
hope. Preemption becomes a dispensatie: `common` code gets inserted yields, `+nefas` code a timer
budget ([cost](02.04.11-contracts-cost-totality.md)).

**Deadlock.** There are no locks in the source (uniqueness grades), only channels, so "can this
deadlock" is "does the channel graph have a cycle", which is what deadlock-free pi typing decides
(Kobayashi, Padovani), delivered per channel library as its theorem.

## 4 Logic and constraint stores

A `space` creates a store segment in the goal's frame (lexical, `../store`); `fresh` allocates a
typed hole in it and `≐` tells into it, both under `out` permission; `+st` is `+in/store
+out/store`, no third computation effect ([history](02.04.10-history-store-distribution.md)). Because
`∨` backtracks by restoring the stack, a goal quotation may not close over linear or unique values
(multi-shot continuations and linear resources are incompatible; OCaml 5 made continuations
one-shot for this reason); a space that needs a linear value is one-shot and the checker refuses
the other case rather than copying silently.

**Search is priced by fuel.** Unbounded search as a single value would carry `+div`; bounded `n
space` is total; the recommended form is `space` as *codata of attempts*, each `next` performing a
bounded amount of search and yielding a solution or "not yet": Capretta's delay monad, the
coinductive rendering of `div`. Every step is total, the stream is productive, the operator chooses
the fuel, and a non-terminating search shows up as a stream that never yields, observable and
loggable rather than a hang. `distribute` makes the strategy first-class; whether it lets
elaboration discharge `+div` statically is open.

**Matching is Prolog inside a space.** Matching is one-way unification, the same algorithm as
`unify`; outside a space it is first-match and deterministic, inside a space with fresh variables it
is two-way with all solutions, and the match rows are Prolog clauses, `[or] fold` the seam's `∨`,
`f/1` the clause path. See the family example in the sketches of
[syntax rationale](02.04.05-syntax-rationale.md) and the typed-position specificity rule in
[objects and dispatch](02.04.09-objects-dispatch-visibility.md). The Prolog row of the paradigm
table reads as one mechanism, two seams.
