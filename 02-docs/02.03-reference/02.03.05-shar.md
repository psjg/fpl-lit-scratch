# 02.03.05 2026-09-28 — SHAR: the syntax hand-off

The syntax author's hand-off was one executable Org shar (the literate, reproducible,
multi-file delivery format; a notice under the project's licence sits inside it). It
carried the work described on the sibling pages:

- `gram/fpl.lark`: the grammar ([surface grammar](02.03.02-grammar.md));
- `gram/test_fpl.py`: pre-lexer, indenter, affix pass, comment attachment and the corpus
  check;
- `gram/printer.py`: the canonical printer and both printer laws as Hypothesis properties
  ([grammar §6](02.03.02-grammar.md#6-the-canonical-printer-and-the-two-laws));
- `gram/fon.py`: FON-data ([FON §9](02.03.03-fon.md#9-fon-data-in-the-prototype-s15-s17-s21-s22-s24-implemented));
- `gram/snips/*.v5.txt`: the language drafts, the counting server and the planted-tree
  sketches (the corpus every claim on these pages was run against).

[FML](02.03.04-fml.md)'s harness (`fml.py`) was owed the same delivery; that page carries
its definitions and evidence until then.

## 1. How it was used

Copy the code block verbatim into a file named `SHAR.org` in a directory of its own, then
`chmod +x SHAR.org && ./SHAR.org`. It tangles `gram/` with the awk in its own preamble and
runs the check in the Nix shell it also tangles; `./SHAR.org tangle` alone needs no Nix.
The inline `#+RESULTS: check-run` is the evidence of one run on 2026-09-28 (lark 1.3.1,
hypothesis 6.168); the `agree` step and the Nix shell were not run at delivery. The block
is the file: every line, tabs included, matters — copy, do not retype. The distributed form
was a 58 009-byte download (sha256 `05710e81769e789bd2be4b8f3a38a38ce0cc46ef10392744d7a9048f883efbef`)
carrying the S40 corpus (`?` goals); a shar of about 1 200 lines with tabs survives a file
download and does not survive a copy from a rendered page. The convention itself is the
`handoff-agentic-shar` skill; the repository's own copy of the same idea is
[`01-bootstrap/handoff`](../../01-bootstrap/handoff/README.md).

## 2. Superseded, with a correction

The repository is now the canonical copy of the grammar, the printer and FON-data; the
shar is kept as the hand-off record and will not be reissued. Its `#+RESULTS: check-run`
says "2000 examples" but the properties inside ran 300 (found by the orchestrating review;
see the correction at the top of [the grammar page](02.03.02-grammar.md)). Also found there
and fixed in the repository, not in the shar:

- the grammar's ambiguity (empty frames, comment-only lines);
- the corpus battery running on import;
- two `#hash` comments in `fon.py` that mean `&hash` (the content prefix moved,
  [spellings S29](02.03.06-spellings-and-comments.md#2-symbol-and--for-content-s29-revising-s16));
- a flake without a lock.

The lesson recorded with it: a claimed figure ("2000 examples") must be tied to the command
that produced it, which is why the grammar page now states the run counts it actually
measured. The decision log that grew beside the shar is in
[FON](02.03.03-fon.md), [binding and matching](02.03.07-binding-and-matching.md) and
[entries, checks and forcing](02.03.08-entries-checks-forcing.md).
