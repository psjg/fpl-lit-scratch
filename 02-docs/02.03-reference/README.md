Information-oriented docs: the language specification and other facts.

- [02.03.01 Errors and diagnostics](02.03.01-errors.md) — `err/` tags, HTTP aliases
- [Spec](spec.md) — the FPL language specification

* [Surface grammar](02.03.02-grammar.md) — The executable surface grammar, its pre-lexer and off-side indenter, the printer laws, and the layout decisions (tabs, no Postel, no semicolon, no colon).
* [FON: FPL Object Notation](02.03.03-fon.md) — The data profile of the one grammar: homoiconic dump, literal subset, ranked whitespace, inert reading, threat classes, spellings, numbers and the serde comparison.
* [FML: the markup companion](02.03.04-fml.md) — The prose profile of the grammar, with prose outside and islands inside; its five layers, Markdown's defects, decisions F1-F20, grammar, printer and open items.
* [SHAR: the syntax hand-off](02.03.05-shar.md) — The record of the executable Org shar that carried the grammar, printer, FON-data and snippet corpus, and why the repository replaced it.
* [Spellings and comments](02.03.06-spellings-and-comments.md) — The spelling axes of FPL text (glyph, name, ASCII), the symbol and content prefixes, tokenizer-aware naming as canon, and the comment forms.
* [Binding and matching](02.03.07-binding-and-matching.md) — Lambdas as binder quotations, positional arguments, patterns as inverse constructors, keyword arguments by records, grammars as match in a space, let/where as child blocks.
* [Entries, checks and forcing](02.03.08-entries-checks-forcing.md) — A word's entries (test, require, ensure, proof) as one ladder, check cells and the caesura, the whitespace ladder, injective views, and the head that forces its children.
