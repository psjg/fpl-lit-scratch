# 02.03.01 2026-10-19 — Errors and diagnostics

Fact sheet for error **tags** and diagnostic chrome. This does **not** invent FPL
language semantics or change the walker printer. Inspiration and sketches:
[Evaluation judgments](../02.04-explanation/inspiration/02.04.03-judgments.md). Live site:
[fpl-lit-scratch](https://psjg.github.io/fpl-lit-scratch/).

## Judgment fail shape (decided 2026-10-29, not printed yet)

```text
|- ! err/<scope>* “<msg>”
```

- `!` — fail marker on the judgment line (not falsum, not a source caret).
- `err/<scope>*` — a path under the `err/` namespace, zero or more scopes (FPL `/`);
  the path is the class of the error: each `FplError` subclass carries one segment, so a
  deeper subclass is a deeper path (`err/unresolved/no-evaluator`).
- `“<msg>”` — the message in FPL quotes (openers and closers symmetric), optional.
- The earlier shape `|- ! err/<tag> : Error [@ <deadline>]` is superseded; the deadline
  `@ <n>` and the position move to the lines under the judgment (the caret block).
- Today’s TTY still uses `ERROR: <line>:<col> <message>`; the flip is the last step of
  [DI-0072](../02.05-project/inbox/DI-0072-a-line-of-numbers-and-a-word.md).

## Paths

The tree being built in `01-bootstrap/fpl/errors.py` (2026-10-29; names may still shift
where the code says otherwise, the pushed code is the reference). Phase 1 lands the
`unresolved`, `no-row`, `out-of-gas`, `stack` and `check` paths; the rest follows.

| Path | Message today |
| --- | --- |
| `err/stack/underflow` | `stack underflow` (it is the stack, so not `err/underflow`) |
| `err/unresolved/unknown-word` | `unknown word: w` |
| `err/unresolved/no-evaluator` | `no evaluator yet` |
| `err/unresolved/goal` | an unfilled `?` |
| `err/no-row` | `no row matches` (404) |
| `err/out-of-gas` | `out of fuel` (408) |
| `err/recursion` | the host's recursion limit, not the meter |

| `err/type/quotation` | `a quotation is expected`; `,` joins two quotations or two lists |
| `err/type/list` | `cons` takes a list; a strand or a list is expected |

## HTTP status aliases

Optional numeric chrome where the HTTP gloss is honest. The **path tag** is the stable
id for fixtures; the number may appear on a banner (`err/out-of-gas  408`).

| Tag | HTTP | Gloss |
| --- | --- | --- |
| `err/out-of-gas` | 408 | Request Timeout — meter / budget exhausted |
| `err/no-row` | 404 | Not Found — nothing matched |
| *(later)* type / refuse | 422 | Unprocessable Entity |
| *(later)* internal | 500 | Internal Server Error — walker bug |

Do not assign a code for every slip. Path-only when no honest HTTP metaphor fits.
