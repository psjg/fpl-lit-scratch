# 02.03.01 2026-10-19 — Errors and diagnostics

Fact sheet for error **tags** and diagnostic chrome. This does **not** invent FPL
language semantics or change the walker printer. Inspiration and sketches:
[Evaluation judgments](../02.04-explanation/inspiration/02.04.03-judgments.md). Live site:
[fpl-lit-scratch](https://psjg.github.io/fpl-lit-scratch/).

## Judgment fail shape (decided and printed 2026-10-29)

```text
|- ! err/<scope>* <line>:<col> “<msg>” @ <n>
|- <value> : <sort> within <n>
```

- `!` — fail marker on the judgment line (not falsum, not a source caret).
- `err/<scope>*` — a path under the `err/` namespace, zero or more scopes (FPL `/`);
  the path is the class of the error: each `FplError` subclass carries one segment, so a
  deeper subclass is a deeper path (`err/unresolved/no-evaluator`).
- `“<msg>”` — the message in FPL quotes (openers and closers symmetric), optional.
- `<line>:<col>` — the position in the source, the second argument (decided 2026-10-29;
  it can be a hyperlink to the place).
- `@ <n>` — on the fail line only: "at step n" of the evaluation, the failing step, the
  address a debugger jumps to. The success line is a different judgment and says
  `within <n>`, a bound: done within n steps (his pick of 2026-10-29, "within" over "in").
  Both left out when not reported. One meaning per glyph: the input number, the old
  `@N` on a session line is `#N`, before the position; no third sign for time, ASCII first.
- The earlier shape `|- ! err/<tag> : Error [@ <deadline>]` is superseded.
- Printed since 2026-10-29 by the TTY loop, the piped REPL, the kernel and the pad; the
  `ERROR:` form has no reader left. The printed fail line pasted back as a closing line is
  the same check, position and step included (a mismatch is `err/check/unmatched-fail`);
  a refusal outside any source prints `|- ! err/session “<msg>”` with no position. Decided in
  [DI-0072](../02.05-project/inbox/DI-0072-a-line-of-numbers-and-a-word.md).
- A read error (`err/read/...`) is judged too: when the program does not parse, the
  closing line is found in the text (the last line that opens with `|- !`, nothing but
  trivia after it) and read on its own, at its own line number (2026-10-31).

## Paths

The tree as built in `01-bootstrap/fpl/errors.py` (2026-10-29): every raise site under
`fpl/` is a subclass of `FplError` with a tag, 51 classes, no bare raise. The class is the
code; the pushed code is the reference where this table lags.

| Path | Covers |
| --- | --- |
| `err/read/...` | lexing and parsing: `unclosed`, `unopened`, `dedent`, `mismatched`, `tabs`, `comment`, `modifier`, `unexpected`, `too-deep`, `number/too-long` |
| `err/unresolved/...` | `no-evaluator` (`no evaluator yet`), `unknown-word` (`unknown word: w`), `goal` (an unfilled `?`) |
| `err/form/...` | a malformed `row`, `pattern`, `match`, `dict`, `effect`, `clause`, `check` |
| `err/ambiguous/...` | two clauses, calls or queries that cross: `clause`, `call`, `query` |
| `err/stack/underflow` | `stack underflow` |
| `err/type/...` | a value of the wrong kind: `number`, `quotation`, `list`, `invertible` |
| `err/shape/...` | `unequal-strands`, `empty-fold` (`fold over nothing`), `each` |
| `err/too-large` | arithmetic past the digit limit (at the root: not a read error) |
| `err/no-row` | `no row matches` (404) |
| `err/out-of-gas` | `out of fuel` (408) |
| `err/recursion` | the host's recursion limit, not the meter |
| `err/check/...` | the `L |- R` check: `unequal`, `unmatched-fail`, `no-fail` |
| `err/print`, `err/session`, `err/fon` | the printer, the session, the FON reader |

The literate pages raise the same leaf classes as the seed, so the tangled walker under
`01-bootstrap/python/` prints the same line (the equivalence lane compares stdout).

## HTTP status aliases

Optional numeric chrome where the HTTP gloss is honest. The **path tag** is the stable
id for fixtures; the number may appear on a banner (`err/out-of-gas  408`).

| Tag | HTTP | Gloss |
| --- | --- | --- |
| `err/out-of-gas` | 408 | Request Timeout — meter / budget exhausted |
| `err/no-row` | 404 | Not Found — nothing matched |
| *(later)* type / refuse | 422 | Unprocessable Entity |
| *(later)* internal | 500 | Internal Server Error — walker bug |

Do not assign a code for every slip. Path-only when no honest HTTP metaphor fits.
