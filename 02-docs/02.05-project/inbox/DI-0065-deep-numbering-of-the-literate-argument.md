# DI-0065 Deep numbering of the literate argument

## His words

> er lijkt een dialectiek in de tekst te zitten een argumentatieschema of boom die van lemma naar lemma gaat … eventueel zou het ook zo genummerd kunnen worden voor structuur… zoals amerikaanse wetgeving dat doet veel dieper doornummeren zoals dat bijvoorbeeld ook zou kunnen in org-mode

## Context

From the summary of web F in the annotation round of 2026-10-28. The library synthesis finds no
text of the genre that numbers its claims; the nearest is a text that numbers cases which later
text cites (keep2013, p. 142). Numbering would give a claim a name other text can cite, which
is what DI-0058 asks of a fragment.

## Options and outcome

Open. Proposal; not implemented.
