## Context

A word has this effect, a slot has this type, a value satisfies this refinement (replaces the handoff's membership sign). One spelling only (`x:Int`, `x: Int`, `x : Int` collapse to one; the lexer must know `:` as a token, today it is a string test in desugar). No `:`-prefixed REPL commands: "dat had ik elders met andere agents zo afgesproken". If a word is needed: `is`, never `in`, since `in` is kept for dialects (in the key of X, under private law).
