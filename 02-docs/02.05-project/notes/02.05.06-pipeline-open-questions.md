# 02.05.06 2026-10-21 — Pipeline open questions

Working note. The review of the compiler pipeline on 2026-10-21 settled a set of decisions,
recorded as [ADR-0001](../adr/ADR-0001-passes-are-pipeable-filters.md) to
[ADR-0013](../adr/ADR-0013-events-observe-not-drive.md). This note keeps the rest: proposals
the maintainer has not ratified and questions left open. Nothing here is a decision. Related:
[ADR-0010](../adr/ADR-0010-first-class-staging.md),
[ADR-0012](../adr/ADR-0012-pipeline-is-a-computation-graph.md) and
[ADR-0013](../adr/ADR-0013-events-observe-not-drive.md), the drafts this note feeds.

Each row gives the state of the tree on 2026-10-21: **implemented**, **documented** (written
down, not built), **partial**, **missing**, or **contradicted** (the tree does the opposite).

## Terminology

| Proposal | State | Where, and what is missing |
| --- | --- | --- |

No glossary states the rule. `AGENTS.md` says "Layered frontend" and "tree-walking interpreter", `roadmap.md` says "semantic frontend", and "reader" names the FON codec. |

## The implementation summary: priorities and non-goals

The review ended in a summary for implementation work, with this thesis: the compiler is a
persistent, typed, dynamically extensible graph of first-class computations, and direct
execution, Unix pipelines, parallel jobs, incremental recomputation and distributed execution
are interpretations of the same graph whose semantics do not change with the executor. The
maintainer asked for the summary; he has not ratified its order or its list of non-goals.

Proposed order of work:

| # | Step | State |
| --- | --- | --- |
| 1 | Replace the closure in `Pass.__rshift__` by structural composition | contradicted ([TD-0008](../techdebt/TD-0008-pass-composition-opaque-closure.md)) |
| 2 | Keep `Pass` callable | implemented |
| 3 | A minimal direct interpreter over structural pipelines | missing |
| 4 | Keep the `fpl <stage>` shell interface | implemented |
| 5 | Make shell execution generic over pass metadata and types, not a stage-name switch | missing |
| 6 | Lossless FON codecs for Syntax and later representations; remove render, re-lex, re-parse | partial: tokens only ([TD-0006](../techdebt/TD-0006-pipe-reparses-rendered-text.md)) |
| 7 | Equivalence tests, direct against shell, per pass and per pipeline | missing ([TD-0007](../techdebt/TD-0007-pipeline-lab-missing-fon-cell.md)) |
| 8 | Graph inspection and visualisation | missing |
| 9 | Only then a dependency or job scheduler | missing |
| 10 | Then dynamic demands, caching, incremental invalidation, parallel compilation per module or function, the process executor, remote execution, the event stream | missing |

Proposed non-goals:

| Do not | State |
| --- | --- |
| replace every pass with an OS process | respected |
| serialise native objects between ordinary in-process passes | respected (`fpl run` keeps ABTs in the process) |
| make events the hidden dependency system | respected (no events) |
| force arbitrary graphs into a shell pipe | respected (no graphs) |
| let `>>` erase graph structure into closures | violated ([TD-0008](../techdebt/TD-0008-pass-composition-opaque-closure.md)) |
| limit what the language can express to gain compiler parallelism | respected |
| let FON perform semantics | respected |
| abandon the transparent Unix and Nanopass workflow | respected |

The non-goals are written down only here.
