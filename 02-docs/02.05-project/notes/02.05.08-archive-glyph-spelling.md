# 02.05.08 2026-09-27 — Archive: the glyph spelling

Kept on 2026-09-27 when S32 made the name spelling the canon. This page is a record, not
a reference: read the [grammar](../../02.03-reference/02.03.02-grammar.md) and the
[syntax rationale](../../02.04-explanation/02.04.05-syntax-rationale.md) for the current
spelling.

superseded-by:: [Grammar](../../02.03-reference/02.03.02-grammar.md)
related:: [Syntax rationale](../../02.04-explanation/02.04.05-syntax-rationale.md)
related:: [Mise en place](02.05.07-mise-en-place.md)

Everything here is a *view* of the same trees the current snippets carry (identity is the
ABT; the printer translates both ways), so nothing is lost by the change, but this is how
it looked when it was first written. The ABT with its glyph, name and ASCII spellings
follows Algol 60's reference, publication and hardware languages
([mise en place §11](02.05.07-mise-en-place.md#11-mined-from-the-195070s)). Two layers:
the very first prototype (the morning's sketch: four-space indentation, no `:` heads, `/`
still fold, strings as names, `?` as the hole, `"print"` as a string), and the last
glyph-spelling versions of the five snippet sets (tabs, `:` heads, `´` fold, `#` symbols,
`_` holes) just before they went to names. The program text below is archival and is
reproduced as it was; some lines wrapped in the source and are rejoined here.

## 1 The very first prototype (morning of 2026-09-27)

```
⍝ ── the language, in itself ──────────────────────────────────

read                                    ⍝ text → lines, each a depth‿tokens pair
    "\n" split
    dup [ ' ' = ∧` +/ ]¨                ⍝ depth: leading spaces (and-scan stops at first non-space)
    swap [ trim ' ' split ]¨            ⍝ tokens
    ⋈¨

blocks                                  ⍝ lines → one block per minimum-depth line: head + its subtree
    dup ⊑¨ dup ⌊/ = ⊔                   ⍝ partition at the lines whose depth is the minimum

node                                    ⍝ block → children-quotations , head-tokens
    dup 1 ↓ blocks node¨ ⊂¨             ⍝ each child block → its code → enclosed: a quotation
    swap ⊑ 1 ⊑ ,                        ⍝ then the head line's tokens

tree                                    ⍝ lines → flat program
    blocks node¨ ,/

apply                                   ⍝ token → effect on the stack
    if
        dup word?                       ⍝ a word: run its definition
        lookup !
                                        ⍝ anything else (literal, quotation) stays put

boot                                    ⍝ text → executed
    read tree apply/

⍝ ── a macro: an ordinary verb on a code array ────────────────

trace                                   ⍝ code → code that prints the stack after every token
    [ "print" ⋈ ]¨ ,/

⍝ ── a user program ───────────────────────────────────────────

graph                                   ⍝ noun-only block: newline = next axis → a 4×4 matrix
    0 3 ∞ 7
    8 0 2 ∞
    5 ∞ 0 1
    2 ∞ ∞ 0

shortest-paths                          ⍝ D → all-pairs shortest paths
    dup ⍴ ⊑ 2 log ⌈ →k                  ⍝ k = ⌈log₂ n⌉
    k ⍟
        dup ⌊.+                         ⍝ D ← D min-plus D   (APL inner product with ⌊ and +)

graph shortest-paths
[ graph shortest-paths ] trace !        ⍝ the same, instrumented
```

## 2 The last glyph-spelling versions (2026-09-27, before S32)

### 2.1 Draft 1

```
read : text -- lines    ⍝ each line a depth‿tokens pair
	newline split
	dup [ tab = ∧` +´ ]¨    ⍝ depth: leading tabs
	swap [ trim space split ]¨      ⍝ tokens
	⋈¨

blocks : lines -- blocks           ⍝ one block per minimum-depth line: head + its subtree
	dup ⊑¨ dup ⌊´ = ⊔

node : block -- code    ⍝ children-quotations , head-tokens
	dup 1 ↓ blocks node¨ ⊂¨
	swap ⊑ 1 ⊑ ,

tree : lines -- code
	blocks node¨ ,´

apply : tok --          ⍝ operative: receives thunks, never syntax
	if
		dup word?
		lookup !

boot : text --
	read tree apply´

trace : code -- code   ⍝ a macro: acts on Code before `:` lowers it to a thunk
	[ #print ⋈ ]¨ ,´

graph            ⍝ saturated frame of literals → a 4×4 matrix
	0 3 ∞ 7
	8 0 2 ∞
	5 ∞ 0 1
	2 ∞ ∞ 0

shortest-paths : D -- D
	dup ⍴ ⊑ 2 log ⌈ →k
	k ⍟
		dup ⌊.+

graph shortest-paths    ⍝ 0 3 5 6 / 5 0 2 3 / 3 6 0 1 / 2 5 7 0
[ graph shortest-paths ] trace !
```

### 2.2 Draft 2

```
⍝ ── frames ──
1 | 1 2 3 +     ⍝ 2 3 4
1 2 3 +         ⍝ [1‿2‿3 +]  a section
2 | 3 +         ⍝ 5
1 | 1 2 3 -˜    ⍝ 1 2 3 - 1

⍝ ── currying ──
curry : x q -- q'       ⍝ [x q]        (BQN ⟜)
	swap ⊂ swap ,
lcurry : x q -- q'      ⍝ [x swap q]   (BQN ⊸)
	[ swap ] swap , curry

⍝ ── operatives ──
my-if : c t --
	swap ! [ ! ] [ drop ] if
when-debug : q --
	../debug [ ! ] [ drop ] if

⍝ ── effects, holes, ascription ──
mean : xs -- x
	dup +´ swap ⍴ ⊑ ÷
median : xs -- x
	dup ⍋ ⊏ _       ⍝ hole: _ : sorted -- x
3 Int ∈
sort : xs -- ys ∈ sorted ∩ xs perm
	dup ⍋ ⊏
	⊢ unfold grade-perm select-sorted qed
	⊨ dup sorted

⍝ ── select ──
select
	words
	doc “∞” ⍷ ∨´
	name effect

⍝ ── constructors run backwards; clauses are an agenda ──
rect   : wh -- shape
	#rect swap ⋈
circle : r -- shape
	#circle swap ⋈
area : shape -- a
	⋈⁼ swap | #circle #rect ⊐
	| [ dup × π × ] [ ×´ ] @.
3 4 rect rect⁼          ⍝ → 3 4

⍝ ── scope follows the tree ──
scale-all : xs k -- ys
	→k
	¨
		k ×

⍝ ── objects ──
point : xy -- p
	| #x #y swap dict
#norm [ | #x #y lookup¨ ×˜ +´ √ ] #point method
3 4 point | norm        ⍝ → 5
take : s n -- xs
	⟨⟩ →acc →s
	n ⍟
		s ⋈⁼ →next →v   acc v , →acc   next ! →s
	acc

⍝ ── ( ) ──
(+ (× 2 3) 4)           ⍝ → 2 | 3 × | 4 +    = 10
1 2 3 +´

⍝ ── quasiquote ──
twice : q -- q'
	[ $q¨ $q¨ ]

⍝ ── laziness ──
nats : n -- stream
	dup 1 + [ nats ] curry ⋈
total $= trade #size col +´
```

The `sort` and `median` lines are transcribed from a flattened print; the glyph runs are
as recovered and may differ from the original in spacing.

### 2.3 Draft 3, the server, and the planted-tree sketches

```
math/
	mean : xs -- x
		dup +´ swap ⍴ ⊑ ÷
stats/
	#math bind
	zscore : xs -- zs
		dup mean - dup sd ÷
math/mean/doc
words/*/effect

serve : n req -- n resp +in/data
	req | #path lookup →p
	../data p ⊐ →text
	text ⍴ ⊑ →size
	n 1 + →n
	| #size size ⋈ #count n ⋈ dict
	n swap
main : -- +in/net +out/net
	../net/in requests →reqs
	0 →n
	reqs [ serve ] n \ →responses
	responses ../net/out reply¨

append : xs ys zs -- +st
	∨´
		[ xs [] ≐ ys zs ≐ ]
		[ fresh →h fresh →t fresh →zs'
		  xs h t cons ≐ t ys zs' append zs h zs' cons ≐ ]
[ fresh →q q [ 1 2 ] [ 3 ] append q ] logic/space     ⍝ → [ [ 1 2 3 ] ]

area : shape -- n
	shape/kind @.
		#circle [ shape/r dup × π × ]
		#rect   [ shape/w shape/h × ]
		_       [ sorry ]
```
