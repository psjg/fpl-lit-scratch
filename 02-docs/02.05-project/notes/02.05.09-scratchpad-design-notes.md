## 2 Reactivity: core, penumbra, frontier

Hart's *open texture* as the navigation rule: what remains open in reactivity is kept
open without vagueness by three layers.

### 2.1 Core: decided, checked

- `signal $= body` binds by identity and the body is kept, not run once.
- Dependency is per reference: `var` is a snapshot, `$var` a cell. The sigil is the
  dependency declaration.
- The clock is the log position *t*; a view is a function of a log prefix.
- Denotation is synchronous dataflow (Lucid/Lustre): every `$=` is a stream over the
  log clock; `fby` is the previous log position.
- Glitch-freedom means all views at the same *t*; `⊨ glitch-free` is a contract on
  handlers, `⊢` once proven.
- Implementation is incremental view maintenance / differential dataflow (C6: the log
  is primary, the store a materialised view).
- Oz dataflow is concurrency, not reactivity: its own row.
- Continuous time is excluded (§8 of the substrate draft); see §3.4 for the seam slot.
- No `lift` / `fold` on signals; `each` / `scan` instead.
- `$name` in a string is a live cell, `⟨expr⟩` a snapshot; S30: `$x` in a quotation
  takes its time from the consumer.

### 2.2 Penumbra: open, permissibly

Push or pull: under glitch-freedom the recomputation strategy is not observable. It is
implementation freedom under one obligation, from-scratch consistency (Acar). When
glitch-freedom is enforced: statically where Lustre-style causality analysis applies (a
`strict/` zone: bounded memory, clocks as types), dynamically as a contract elsewhere:
two rungs, one property. A spliced value and a live cell in one quotation (S30 ×
glitch-freedom): the quotation's type says which.

### 2.3 Frontier: refused today, by name

- `$var` in an ordinary `:` definition is **refused**. A `:` definition is a snapshot
  function; a view is written `$=`. Widening later is cheap, narrowing breaks
  programs, and the corpus is small.
- Continuous time: a seam-kind slot, `seam _ ∈ time -- core`, filled when hybrid
  systems arrive.
- Concurrency (Oz, Kahn, E): its own row, never merged with views.
- Cycles in `$=` (X12), revised: refused unless the cycle says what it is. Excel is
  the precedent for the refusal (circular references are an error until iteration is
  switched on); what it lacks is saying *why* a cycle converges.

| kind of cycle | what it is | law | spelling |
| --- | --- | --- | --- |
| through a delay | `x $= y fby 0`, `y $= x 1 +`: a cycle across time, not within one *t* | no solver; Lustre's causality analysis permits cycles through `pre`/`fby` and forbids only instantaneous ones | `fby`; already in the core |
| monotone on a lattice | cells accumulate information (propagators; Datalog; the e-graph's `saturate`) | Kleene: monotone functions on a lattice of finite height converge, guaranteed; contradiction is a state, not an error | cell type is a lattice (`∈ lattice`); `⊢ converges` proven |
| numeric relaxation | Sketchpad, Excel's iteration, Jacobi/Gauss-Seidel | converges only for a contraction, else `+div` | `⊨ converges` as a contract with iteration and tolerance bounds |

The core semantics stands: a fixpoint iteration happens *within* one log position *t*
(Esterel's instantaneous reaction, Statecharts' super-step) and the view's value at *t*
is the fixpoint; delays go *across* *t*. A bare instantaneous cycle with none of the
three stays an elaboration error; `sorry` on it is the opt-in that says "not yet
decided which".

The navigation rule in one sentence: the core is the denotation and is checked; the
penumbra is strategy and must be invisible; the frontier is refused with a `_` in it,
and every refusal that a real program hits becomes a row. Uncertainty lives in named
holes, never in silent behaviour. See [UI](../../02.04-explanation/02.04.06-ui.md) U3
for how layout reuses the same propagation.

## 3 Decisions recorded in the log, by theme

### 3.1 Capabilities, effects, failure

- **Row 25**: input and output are two capabilities, never one `io`: `in` is a source
  (integrity polarity, `F A`, shareable), `out` a sink (confidentiality polarity,
  `A → F 1`, unique). `+io` is superseded by `+in/…` and `+out/…`.
- **Row 26**: purity by absence. `div` and `Fail` are the only computation effects;
  everything else is a capability. A definition with no capability parameter is
  syntactically pure; the default fragment is total, pure and non-failing.
- **Row 27**: checked failure without Java's failure. `+fail` is inferred and
  effect-polymorphic; *caught* is structural, *where-caught* is a query on the creation
  chain, *caught-well* is exhaustiveness via offered restarts in the type. Condition
  kinds are paths. `Option`/`Result` coexist for caller-decidable outcomes.
- **Failure on the syntax side**: Icon/SNOBOL success-failure per frame. Words fail
  (control), array elements are null (data); `∨` alternation, `,` sequencing; failure
  is total and pure, no capability. Generators are pull streams (list of successes),
  so no `../ctl` capability is needed. `unwrap` (Option → `+fail`) and `try`
  (`+fail` → Option) are seam words.
- **Row 35-36 (`+st`)**: `+st` is `+in/store +out/store` on a store segment created
  lexically by `space`; no third computation effect. `space` is priced by fuel as
  codata of attempts (Capretta's delay monad), so no `+div`. `∨` cannot capture linear
  or unique values because backtracking restores the stack.
- **Mutability**: values are immutable; `→x` is mortal, so same-scope rebinding is
  shadowing; `bind` later-shadows-earlier with `history`; in-place update is an
  implementation fact from uniqueness (FBIP/Perceus), never a language fact; shared
  state only as cells at a log time. The write word is `set : v cell -- +st`. Grades
  do not brake reading (ω is the default); a grade counts consumption.
- **Row 43**: bare `/` is panic, typed and supervised. A bare-metal image restarts as
  checkpoint + log replay with invariant-at-checkpoint, restart intensity and a
  log-only loader.
- **Rows 47-50**: write-ahead for effects (log first, then channel); recipes as
  `&`-closures over an origin; certified checkpoints `{ frontier, tree:
  blake3(M(frontier)), attestation }`; a fourth, semantic search index that is a
  bit-exact function of content-addressed inputs, certifiable and never authoritative.

### 3.2 Scope, objects, dispatch

- **Row 15** (rewritten): `./` is self; `../` the enclosing scope and supervisor
  (creation chain, not call stack); bare `/` escalation with offered restarts pushed as
  quotations; the global root is unreadable and has no spelling. `./x` is bound here,
  `../x` inherited, `./norm` a send to self.
- **Rows 16-21**: condition system = effect handlers as restarts + supervision along
  `..`; `⍣` is a local supervisor. OOP: the object half in (coalgebra, late binding by
  path, encapsulation by capability and sealing, structural `has/` interfaces,
  prototypes by ordered union mount, actors with a mailbox), the class half refused
  (implementation inheritance, nominal subtyping, `null`, implicit `this`).
  Multimethods (`@.` on tag tuples, mount order not class precedence), advice as
  handlers around a send (installable only by a capability holder), metaclasses and the
  MOP behind `../meta`, branding via sealing and bisimulation instead of Liskov.
- **Row 18 amendment** (typed dispatch, option B, confirmed 2026-09-30): the most
  specific clause wins; crossing typed positions are an error at the later head; newest
  is the tie-break; a word's interface is the *set* of clause signatures; a new
  signature is minor only if its domain is disjoint from every existing clause's,
  otherwise major because it captures calls.
- **Row 22-24**: visibility as facets and grants (dunder dissolves); authority static by
  default, the authority graph an artefact (R9: the graph bounds the log); gradual
  loosening with `?`+`sorry` holes and blame, resource safety never loosened.
- **Rows 31-32**: the keyring scope is `../adyton/` (granting a key is a *dispensatie*,
  a word using one carries `+nefas`); dynamic scope is the reader effect `+ctx/…`,
  installed only by capability holders; two trees (creation via `..`, call via
  `/proc/self/stack`).
- **Row 56-57**: profiles as privileges: `#ML under` mounts a directory of keys,
  defaults, sugar and a view at the scope root, logged, in the interface hash;
  `common` is the regime holes are counted against; tightening (`ML` →
  `ML/reproducible`) is a diff of obligations shown in advance. A view is a directory
  entry under `⊨ read ∘ print = id`. The musical reading (tonic, modulation,
  resolution) is explanatory only.
- **Contracts (rows 40-42, 72)**: `require` / `ensure` / `rescue` are children of the
  word's directory; the printer order is doc, require, body, ensure, rescue; the
  interface view is that list without the body, and the interface hash covers it;
  `old` is a word; aliases (`pre`, `post`) are canonicalised. The object invariant must
  hold at escalation. S44/S45 then make them prelude macros filing `./name/`.
  See [Mise en place](02.05.07-mise-en-place.md) for the fixed order of a word.

### 3.3 Identity and the store

- **Row 39**: `&` names bytes (by hash), `$` what was hashed at birth (identity), `#` a
  symbol (petname). Identifiers are self-describing multihashes spelled in decimal:
  `&30:<digest>` (code then digest, no leading zeros); raw bytes are stored, decimal is
  the print; one current code per store; history never rehashed; alias events link two
  codes for one content; the inline code `&0:<length>:<decimal>` is for `&` only; short
  forms are prefixes of the digest digits. Measured on two tokenizers: 29 tokens for the
  decimal spelling, 40 for the hex multihash. An atom is `$event/offset`.
- **Row 28-30**: single-level store (the content store is the address space; `in`/`out`
  are permission bits on a segment capability; RAM/disk is residency, a third grade
  semiring, `pin`/`prefetch` capabilities); the distributed OS reframed as shared
  history (local-first segments, remote authority as channels with `+fail`).
- **Rows 44-46, 48-49**: erase-your-darlings is C6 by construction; the log is a
  bitemporal database, the image rewindable and forkable; v0 is the *history layer* (a
  journal), with vcs / format / package / filesystem / database as views; in the nPOV
  reading CRDT convergence is the sheaf condition and a conflict is where gluing fails,
  kept as a hole (R11).
- **Row 65**: semver as a computed view of interface diffs; `& use` / `$ use` / `# use`
  as import modes; packages as data plus granted capabilities.

### 3.4 Numbers, algebra, differentiation, symbolics

- **Row 33**: FPL is symbolic by tier: level-1 symbolic language (e-graph with AC
  theories), residual generator at level 0, run-time symbolics only through
  `../adyton/reflect`.
- **FPL\_smooth**: the differentiable fragment is *derived, not fenced*: each Real
  primitive carries its derivative as an obligation on a rung (`sin ⊢`, `exp ⊨` finite
  differences, `relu ∈` with a hole at 0); a word is in FPL\_smooth iff all its
  primitives' obligations close without `sorry`; `Int` is outside for lack of any
  obligation. Reverse mode is CHAD using grades; neurosymbolics via provenance
  semirings. Row 52: "over the denotational model of the type; representations carry
  their own obligations."
- **Row 39a angles**: the turn is the unit (`turn : -- Angle`); `Angle` is a type;
  τ and π are library words. Split: `Angle = ℤ[1/2^k]·turn` (keeps winding),
  `U(1) = ℤ/2^k·turn` (overflow is the circle); `exp` is a mask to the low k bits.
- **Row 40a hypercomplex**: no algebra is primitive; an algebra is data over the array
  carrier, laws are obligations on a rung; Clifford `Cl(p,q,r)` is the right ladder
  (not Cayley–Dickson); the scalar ring is an explicit parameter.
- **Row 55**: the representation lattice (binary/decimal × fixed/floating), each
  discharging ℝ obligations with its own error model; `Money = Int × Currency` with a
  rounding-policy obligation.
- **Rows 51-54, 70**: FPL as an ML workbench; integer training is the reproducible
  default; inference nondeterminism is lack of batch invariance, so a level-1 schedule
  may not read the batch size; the array core is a tiny tinygrad-class lazy op set (T4)
  with rank polymorphism as theorems over it; `/fpl/lib/cat` is the structural spine,
  index origin a profile default.
- **Rows 58-63**: parallelism in three classes by what is logged (deterministic
  parallel; deterministic concurrency / Kahn, membership by capability absence;
  nondeterministic as logged choices); scheduling contexts as capabilities; cost as a
  third grade semiring (AARA as grade inference); totality as a five-rung ladder.
- **Rows 72-78**: two kinds of rewriting (computation vs equality; a declared theory is
  correct iff its axioms are bisimulations); macros as level-1 functions over the ABT
  with hygiene as a scope capability; the compiler as a nanopass pipeline;
  `cost@M` relative to a content-addressed machine model; ISA↔HDL as refinement;
  observations as an `out` capability with a leakage contract; speculation as a hard
  limit (secret plus untrusted code needs separate images).
- **Rows 84-85**: the plane: 2LTT's outer level as the surface where every object
  theory is a universe with none privileged; morphism judgments `T ⟶ T′` with loss
  lists (`/fpl/formal/plane`); R3 restated as per-theory consistency plus per-morphism
  soundness; Alice ML shows a typed runtime metavariable has shipped, so `fresh` is a
  promise with a uniqueness grade.

### 3.5 Syntax and grammar (from the log)

- **Tokenizer** (Forth style): whitespace separates tokens; only the modifier set
  `´ \` ¨ ˜ ⁼ ˙` splits off a name's tail. Indentation is tabs, one per level; alignment
  is a view (elastic tabstops); leading spaces are an error; the canonical printer is the
  only normaliser. Postel's rule was removed entirely.
- **Holes**: `_` is the hole the elaborator fills (wildcard, inference), `?` the goal it
  reports (S40); `unwrap` is a word.
- **Sigils**: core prefixes `→ $ # & .. /` plus modifiers; `#name` symbol, `&hash`
  content (S29); `$name` a cell, `$code:digest` an identity, `$n` the n-th argument,
  separated by the colon (X13 discharged).
- **Comments**: comments are nodes with a level bound to position (`;` after code,
  `;;` doc, `;;;` section, `;;;;` file); block comment `<!-- … -->` is a raw-text node
  that nests (S48); `; →` as a checked claim was withdrawn: expected values come only
  from `⊨` check cells and `test` rows (S45).
- **Checks**: `⊨`/`⊢` are words; in canonical text a check is the last cell of a line
  (`code⇥| 0 >= ⊨`); a check observes linear items through a read-only borrow.
- **Patterns**: `match` is an ordinary word; each row runs its pattern *inverted* then
  the body, rows combined with `or` which restores the stack; patterns follow from
  inverses (name ↔ binder, literal ↔ equality, constructor ↔ destructor); `_` respects
  grades. Typed slots `name: Type`, `→x: Int`; `∈` withdrawn (S49).
- **Every view is injective** (S47): two different trees never look the same in any view;
  numbers and hashes are full decimals, no separators.
- **`( … )`**: Lisp prefix notation, the head moved to the end and each argument its own
  frame; bars needed only between adjacent literals.
- **Grammar harness**: both printer laws (parse∘print = id, print idempotent) hold as
  property tests at 2000 examples (earlier runs were 300 and are corrected); FON-data
  prototype, with strings leaving the context-free grammar via a counting pre-lexer.
  See [Grammar](../../02.03-reference/02.03.02-grammar.md),
  [FON](../../02.03-reference/02.03.03-fon.md) and [SHAR](../../02.03-reference/02.03.05-shar.md).

### 3.6 Implementation and planning

- **Row 37/38**: no early self-hosting. The Python reference is the executable spec;
  the AST walker comes first and is never discarded (it is the level-1 runtime); then
  residual → backend; bootstrap is a differential milestone. See the
  [bootstrap passes](../../../01-bootstrap/01.02-pass/01.02.10-evaluate.md) and the
  [backend plan](02.05.06-backend-plan.md).
- **Row 81-83**: WebAssembly before Perceus-C; own reference counting in linear memory;
  `cost-label` is an observation; `asm-common` is the common layer; effects live on the
  returner; `fail` reaches its lexically bound supervisor.
- **Row 79/80**: dependent-kernel bootstrap (meta level first; kernel nodes K1–K10);
  M1 is a node without typed patches, M2 splits into M2a/M2b, C1/C2 gain a reclamation
  test.
- **The REPL is a tool, not a route**: it changes no precedence in the work graph but
  speeds nodes up; a measured gain sweep shows it pays at any gain above zero. See
  [REPL phrase costs](02.05.05-repl-phrase-costs.md).
- **Conventions principle**: conventions lower perplexity for agents; naming classes are
  enforced (error, not warning); Hungarian kinds are checked against the inferred type;
  `MAIN.fpl` manifests; see [Mise en place](02.05.07-mise-en-place.md).

## 4 Parked ideas (not decisions)

- **Hole queries as synthesis**: ask a hole "which words take me from A through ? to B";
  type-directed program synthesis (Hoogle, `exact?`, Djinn, Myth, Rosette, Synquid).
  Fits FPL because composition is the only glue, so `A → ? → B` is a path search in the
  graph of effect lines, which is already queryable data. Search is bounded (`n space`);
  SMT only over a decidable predicate fragment; ranking needs a prior.
- **Dependent types in the dataflow**: a type may depend on a cell and then is itself a
  view (`Vec n` snapshot vs `Vec $n` live). Glitch-freedom becomes type safety; "always
  well-typed" is an invariant over the log (FRP ↔ linear temporal logic). Rule proposed:
  a `:` definition's effect line is static; live types exist only in `$=` views.
- **Modules, dependencies, actors, leases, patching**: every directory may have a
  `./MAIN.fpl`; dependencies readable and changeable, deduplicated by content address;
  patching at three levels (by hash, lexical refinement, overlay under a dispensation,
  contract kept: effect line equal, `require` no stronger, `ensure` no weaker);
  locality as a coeffect lattice (same core, NUMA node, memory space, machine);
  migration after Emerald; leases as capabilities with a time-dependent refinement
  (safety never depends on a clock bound); model checking as a rung between properties
  and proof.
