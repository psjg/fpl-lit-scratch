### 6.1 M1 as a ladder: what can be left, and at what price

M1 first read "no single *equality* is fundamental; FPL is a platform, not a language." It
is now a ladder: the hub is laid as low as it goes, three rungs, each with whether it can be
left and what leaving costs. **Neutrality is not promised; exit is.**

| Rung | Can it be left? | Price |
| --- | --- | --- |
| The language of the morphisms (the 2LTT meta level) | No: leaving it is silence, not exile; without it there is no functor, so nothing sees you and you see nothing | none |
| Binding structure | Yes | Hash of bytes instead of hash modulo α; no e-graph, no typed patches; the only seam available is the "neither" kind (a parser). What remains is a content-addressed blob store plus a seam declaration: git |
| The named centre (CBPV with grades and capabilities) | Yes | Per functor: the loss list of that seam (§5a), stated by the system, not by the maintainer |

**Consequences.** The carrier of representation lies below CBPV: stored identity is
syntactic, CBPV's equality is one declared theory in the e-graph, privileged by default and
by its definition, never by primitiveness. A second centre of interaction (FPL2's) is then
a second inhabitant beside the first, not a migration. The centre is declared in the same
terms an operator declares a theory; declaring a theory plus its functor is an ordinary
library act with a checked obligation. Leaving a rung is a voluntary, priced exit whose
price is an object in the system (Agamben's ban as inclusive exclusion: the exile is inside
the plane exactly as far as its seam reaches). This settles X9.

**The image for draft 5 §1: a garden.** The ladder is the reviewer's artefact; the prose
image is a garden. The 2LTT meta level is the plane of consistency, the ground, inside and
outside alike. The wall around the garden is binding structure. Inside stand declared
theories as trees; the largest, for now, is CBPV, because it is the default and has a
definition, and most work happens under it. The gates are open in both directions: leaving is
a priced choice, not a fall, and a parser brings the nomad back in. Anyone may plant; the
first gardener was only first, not owner. Where the image and the ladder disagree, the ladder
wins: it carries the price column and the image does not.

### 6.2 Lineage of M1

The ladder is a position in an older argument: neither tree nor rhizome. Floyd's 1978
Turing lecture imported "paradigm" from Kuhn; Backus (1977) and Kowalski (1979) filled the
frame with the functional and logic manifestos, and by the mid-1980s the four-way split
(imperative, functional, logic, object-oriented) was textbook furniture. Van Roy and
Haridi's *Concepts, Techniques, and Models of Computer Programming* (CTM, 2004) turned the
flat list into an ordered lattice (start from a kernel language, add one primitive per
layer, and relations between paradigms become theorems). Krishnamurthi ("Teaching
Programming Languages in a Post-Linnaean Age", 2008) and the Racket line reject the
taxonomy: languages are bags of features, `#lang` makes each one a library. M1 takes CTM's
edges (a named loss per added primitive) and Racket's reflexivity (the default is itself a
library) and drops both roots: the tree's single kernel and the rhizome's pretence of
having none.

Oz is CTM's executable and the one place the lattice was actually built. Its construction
is the template for a seam's loss list (§5a):

| Layer | Primitive added | What survives | What is lost |
| --- | --- | --- | --- |
| Declarative kernel | dataflow variables, procedures, records | determinism, referential transparency | none |
| Declarative concurrency | `thread` | determinism (confluence): result independent of scheduling | none |
| Lazy | `lazy` / by-need | determinism | strictness as a cost model |
| Explicit state | cells (`NewCell`, `:=`) | none | determinism; equational reasoning across a cell |
| Message passing | ports (`NewPort`, `Send`) | dataflow on the receiving stream | order of arrival (nondeterministic sends) |
| Exceptions | `try`/`raise` | none | totality |
| Search | choice points, computation spaces | encapsulated nondeterminism | none (nondeterminism is scoped, not global) |

Direct value for FPL, and the whole of it:

1. **Runtime holes.** Oz's unbound dataflow variable is a metavariable at runtime that
   suspends its consumers until instantiated; Hazel has the typed, editor-time half. C2's
   "holes as exposed metavariables" is the product of the two, and Oz is the existence proof
   that the runtime half works, untyped. Whether anything has shipped the typed runtime form
   is not verified; the draft should not claim novelty until it is.
2. **Handler contracts in C4.** Each concurrency handler should state which CTM theorem it
   keeps: confluence, determinism given no shared cells, or neither.
3. **The loss column.** The table above is what a seam kind's loss list looks like when
   written per primitive rather than as full/faithful/neither.

Nothing else transfers: Oz is untyped, has no provenance, no staging, no content addressing,
and the last release is 2.0.1 (2018). The paradigms Oz lacks are close to one-to-one with
what this substrate adds over CBPV (staging and reflection, grades and dependent records,
the array and concatenative surface, symbolic computation, literate delivery). The reason
is structural: CTM's lattice orders extensions of the *dynamic* semantics only. A type
system, a stage distinction or a grade is not a primitive added to the kernel; it changes
what a term is. That axis the lattice cannot express, which is why the 2LTT meta level is a
second axis in this design and not another rung.

## 7 Sketches: planted trees

Nothing here is decided. It is written in the surface syntax so the shape can be seen, and
every word not in the [grammar](../../02.03-reference/02.03.02-grammar.md) is marked
`⟨sketch⟩`. What is fixed and reused: `:` heads with stack effects and `+cap`, `→x`, `|`
frames, `..`, `[ ]`, `¨`, `?`, `∈ ⊢ ⊨`, paths, and that a head line ending in `/` mounts
its children, so a theory is a directory. Every tree has a `seam` entry declaring the
functor into the carrier and its kind, so planting and stating the price are one act. (The
spelling here is the syntax author's pass of 2026-09-27; the earlier glyph form is in the
[archive](02.05.08-archive-glyph-spelling.md).)

determinism theorem stops applying and nowhere else. A logic variable is the `?` hole of C2
with a type, and a finite domain is a hole with a domain: Oz's construction on the
substrate's own holes. Rules are the e-graph exposed. Reactive is a C4 handler with a named
contract. Multiple dispatch closes the open case with `sorry`, which is P2 doing its job.

and retraction as a fact: a knowledge base without a curator, and therefore without an
answer to reference, which is owed separately. **What is not shown:** how `or` interacts

accepts), how a `space` is priced when it fails to terminate, whether `seam` is a word or a
kind, and the spelling of everything marked `⟨sketch⟩`.

## 8 FPL_smooth and neurosymbolics

**Differentiable programming is a functor, not a language style.** Automatic differentiation
(as opposed to symbolic) needs no program-as-data: forward mode is operator overloading on
dual numbers, reverse mode a runtime tape, and categorically the interpretation must factor
through a Cartesian differential category (Blute–Cockett–Seely) or, for reverse mode, a
reverse-derivative category (Cruttwell et al.); Elliott's "The simple essence of automatic
differentiation" gives AD as a functor with no symbolic step. The functor is *partial*:
defined on the smooth fragment, undefined elsewhere, and undefined costs nothing.
Smoothness must be visible in the type or grade, not in the behaviour (Julia/Zygote, where
everything is nominally differentiable and an integer branch yields zero silently, is the
counterexample).

**`FPL_smooth` is a derived property, not a fence:** a word is in it exactly when every
primitive it composes has its derivative obligation closed without `sorry`. Status: nothing
differentiates today; "partial" means the functor is described, not built. It takes three
existing things and one functor:

1. *The derivative as an obligation on a rung.* A primitive on `Real` carries its
   derivative the way any claim is carried: `⊢` proven, `⊨` checked at run time (finite
   differences as a contract), `∈` declared. `sin` closes at rung 1, `exp` at rung 2, `relu`
   at rung 3 with a hole at 0 that a chosen subgradient or a `sorry` discharges. No primitive
   table beside the language: the table is the primitives.
2. *Openness as an effect.* A word composing a primitive whose obligation is open carries
   that openness, exactly as `+div` is carried until `n space` discharges it. `Int` is
   outside because no primitive on `Int` has a derivative obligation at all.
3. *D as a seam with one obligation.* Forward mode is a lift over words; reverse mode is
   CHAD (Vákár and Smeding, TOPLAS 2022; Brunel, Mazza and Pagani, POPL 2020 as linear
   negation), a structure-preserving functor into a target with linear types, which here
   are grades (C2). The seam's own obligation is the chain rule, once.
4. *Control flow through staging (C5)* once the fragment goes beyond straight composition.

"Smooth" is the right word (continuous admits `abs`, and AD needs at least C¹, higher-order
AD C^k), but the fragment is not named by a predicate on types; it is read off the
obligations. AD earns its place beyond neurosymbolics: gradient-based fitting, sensitivities
of ODE solutions (P3's continuous time makes this a first-class need), Hamiltonian Monte
Carlo, Newton and root finding, differentiable rendering and simulation.

**Neurosymbolics needs saturation to be a smooth function of weights.** Provenance
semirings (Green, Karvounarakis, Tannen, PODS 2007) parameterise a Datalog engine by a
semiring: boolean gives classical logic, probabilities give ProbLog, a differentiable
semiring gives Scallop (Huang et al., NeurIPS 2021; PLDI 2023). Łukasiewicz-style fuzzy
logic is one choice of semiring, not the precondition. In the garden `rules/saturate` and
`facts/` take a semiring parameter; the neural side is an ordinary smooth word
`image -- weights`; with the differentiable semiring `saturate` is a word in that same
fragment and D runs through it. The symbolic part stays symbolic (same e-graph); only the
aggregation is smooth. After steps 1–2 and the semiring parameter, a first demonstration is
possible: forward mode over Scallop-style saturation, without reverse mode and without
control flow.

## 9 What the ladder does and does not cover

Nothing in FPL is implemented; "in the draft" means a mechanism is named for it. Against
the paradigms Oz does not cover:

| Paradigm | In the draft? | What has to happen, or how it works | Lost against the status quo |
| --- | --- | --- | --- |
| Metaprogramming | yes | homoiconic postfix plus staging (C5); hygiene for the macro layer is undesigned; reflection a declared theory | Racket: `#lang`, scope-set hygiene; Lisp/Smalltalk: unrestricted runtime redefinition (gated here) |
| Generic programming | yes | dependent records and grades (C2) give parametric and ad-hoc abstraction; instance resolution undecided | C++: instantiation without a declared interface; Haskell: global coherence machinery |
| Visual programming | no | a projectional view: a functor from the carrier to diagrams, edits back as typed patches | LabVIEW, Simulink, Max: everything |
| Reactive | no | spreadsheet-style is propagation to a fixed point (the `fd/` store, Cassowary as a linear sibling, retract then re-propagate, incremental because propagators run only on changed inputs); stream-style (Elm) is a C4 handler; saturation, propagation and simplex are the garden's three fixed points | Cassowary: an incremental simplex to write; Elm, Rx: stream operators, glitch-freedom as a proven contract |
| Prototype-based, object-based, DCI | yes (object half, M39) | an object is a directory, a prototype is `bind` of its directory under yours, a lookup that falls through is delegation; DCI roles are directories union-mounted for the duration of a `\|` frame | Self, JavaScript: nothing; Smalltalk, Java: the class half, refused by decision |
| Symbolic | yes | the e-graph over a declared theory; pattern-matching rewriting as an operator-facing feature is open | Wolfram: term rewriting as default evaluation |
| Differentiable | partial | §8 | JAX: composable transformations and maturity; Dex: typed index sets |
| Literate | yes, as delivery | deliverables are literate documents (the [SHAR](../../02.03-reference/02.03.05-shar.md) form); whether the source form itself is literate is open | Org-babel, noweb: nothing |
| Array | yes, in the syntax | rank polymorphism as a typed theory is open; leading-axis agreement stated as intent, not typed | APL, BQN, Uiua: implicit rank iteration as untyped defaults; terseness |
| Linear, affine, ownership | yes | semiring-graded types (C2); inference is the gap | Rust: lifetime inference, NLL, ecosystem |
| Dependent | yes | 2LTT with dependent records; object-level strength, termination and universe levels to fix | Agda, Idris, Lean: tactics, automation, mathlib |
| Multiple dispatch | no | a library over dependent records; open runtime extension sits in a loosened region | Julia: open dispatch plus specialising JIT; CLOS: method combination, MOP |
| Event-driven | partial | events are effects handled in C4 | JavaScript: the event loop as global default |
| Actor | partial | message passing as a C4 handler; supervision, failure and hot loading as handler contracts | Erlang/BEAM: supervision trees, hot loading, operations |
| Knowledge-based | no | a `facts/` tree: signed, mountable Datalog facts (Datomic-style append-only, egglog); contradiction a recorded state; a reference tree saying which terms denote the same thing is still owed (the hash of `Paris` is stable and is not the city) | Wolfram, Google: the curated graph |
| Logic | no | a declared theory with a non-full seam: unification and search encapsulated (Oz's computation spaces); unification over the content-addressed carrier is a research item | Prolog, miniKanren: search as default evaluation and cut |
| Constraint | no | propagators over a store as a declared theory; holes as runtime metavariables with a domain | Gecode, MiniZinc, Oz: propagator libraries, search strategies |
| Rule-based | no | a theory over the e-graph; forward chaining is saturation | CLIPS, Drools: Rete networks and conflict resolution |

**Refused as a default, only at a price.** The ladder refuses nothing outright; three things
it refuses to make free.

- *Dynamism.* FPL cannot be a dynamic language the way Python, Lisp or a Smalltalk image
  are. Loosening exists only as a region the compiler wraps in a hole discharged with
  `sorry`, so dynamism is always priced and yields a task list. FPL does not demand that
  everyone be static; it invoices. Every large dynamic codebase pays the same debt later
  (mypy, TypeScript, Sorbet) without an index of where the assumptions sit.
- *Runtime self-modification.* Available at the same price. A program is a content-addressed
  term (C1) and staging (C5) makes it available as an object, so self-modification is a term
  that produces a new term and moves a reference, a cell holding a hash. Nothing is
  overwritten, so the old code stays addressable: self-modification becomes self-versioning.
  Each modification is a typed patch; skipping the type check leaves a hole with `sorry`.
- *A non-deterministic centre.* Not excluded. CBPV is the named centre by default and by its
  definition, never by rank; "default" means what an operator gets when saying nothing, not a
  root. Anyone may plant a π-calculus, interaction-net or game-semantics tree; it lacks only
  the definition and the libraries, which is work, not rank. Dancing between trees needs a
  seam: because the carrier lies below CBPV, an interaction-net tree and the CBPV tree are
  siblings on the same carrier, and a functor between them (CBPV into polarised L,
  Munch-Maccagnoni, is one, already written) lets a program use both.
