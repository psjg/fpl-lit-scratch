# Git hooks

* [atomic-check](atomic-check) - Soft check that a commit stays one change
* [commit-limits](commit-limits) - Generated header and body length limits
* [commit-msg](commit-msg) - Validate the commit message
* [commit-rules](commit-rules) - Shared rules sourced by hooks and acommit
* [pre-commit](pre-commit) - Leak check and refuse commits on main
* [pre-push](pre-push) - Leak, forward-only, branch names and commit-lint
* [prepare-commit-msg](prepare-commit-msg) - Fill the commit template trailers
* [reference-transaction](reference-transaction) - Let main move only with its upstream
