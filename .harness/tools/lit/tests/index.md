# Lit tests

* [test_web](test_web.py) - how a page is read and tangled, and every finding of the web
* [test_cli](test_cli.py) - tangle and check: read-only files, rewrites and drift
* [test_lint](test_lint.py) - names in the prose, and the examples of a page
* [test_readable](test_readable.py) - facts from asserts, safe answers, scoring, the command line
* [test_run](test_run.py) - tool output read back to page lines
* [test_weave](test_weave.py) - the HTML of a page: sections, links and indexes
* [support](support.py) - shared helpers: fixture pages and the command line
