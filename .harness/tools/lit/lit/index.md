# Lit package

* [__init__](__init__.py) - __init__
* [__main__](__main__.py) - the command line: tangle, check, lint, weave, readable, run
* [web](web.py) - a page read into sections and chunks, and tangled
* [lint](lint.py) - the prose and the code agree; the examples run
* [readable](readable.py) - facts from the tests, asked of a model that reads only the prose
* [run](run.py) - tool output read back to page lines
* [weave](weave.py) - a page as one HTML page, with indexes
