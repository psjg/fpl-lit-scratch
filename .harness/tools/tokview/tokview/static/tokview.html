Each coloured run is one token (BPE colours off shows the plain text); a colour that runs from the indentation or across a cell gap into a word is one token spanning the tab. A red underline marks a token that fused across a boundary: a comment marker glued to the text after it, or a tab (indentation or a cell edge) glued to the text after it; a character in a red border with a small count is one that the tokenizer broke into that many byte fragments; click it to see them. Leading tabs are indentation (plain space, its width is the indent setting; shaded only when whitespace is shown; the red vertical line is the column width); later tabs separate cells, laid out as elastic tabstops: in a run of consecutive lines a column is as wide as its widest cell. The text itself is never changed by the indent or gap settings; the wrapping setting rewrites comments only, by the conventions under discussion, and never code.
